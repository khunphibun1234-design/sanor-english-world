# คู่มือตั้งค่าฐานข้อมูล Supabase (ครูทำเอง ประมาณ 20-30 นาที)

**กติกาสำคัญ:** ห้ามส่งรหัสผ่าน โทเคน หรือ service_role key ให้ใครในแชท ค่าที่ใส่ในแอปได้มีแค่ 2 ค่า คือ Project URL และ anon public key (ตั้งใจให้เปิดเผยได้ ความปลอดภัยอยู่ที่ RLS ใน schema.sql)

## ขั้นที่ 1 สร้างบัญชีและโปรเจกต์
1. สมัคร supabase.com ด้วยอีเมลของครู **เปิดยืนยันตัวตน 2 ขั้นตอน (2FA)** ที่ Account > Security
2. New project: ตั้งชื่อ sanor-english-world เลือกภูมิภาคใกล้ไทย (Singapore) ตั้ง Database password แล้วเก็บไว้ในที่ปลอดภัย
3. ผู้ให้บริการอยู่ต่างประเทศ ต้องแจ้งไว้ในหนังสือยินยอมผู้ปกครอง

## ขั้นที่ 2 ตั้งค่าการยืนยันตัวตน
1. Authentication > Providers > Email: **ปิด "Confirm email"** (นักเรียนไม่มีอีเมลจริง ถ้าเปิดไว้ สมัครไม่ได้)
2. Authentication > Sign In / Providers: ตั้ง minimum password length เป็น 6 ขึ้นไป
3. Authentication > Rate Limits: คงค่าเริ่มต้นหรือเข้มกว่า (กันคนรัวสมัคร)

## ขั้นที่ 3 สร้างตาราง
1. SQL Editor > New query วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งไฟล์ กด Run (รันซ้ำได้ ไม่พัง)
2. ตรวจ Table Editor ว่ามีตาราง students และ submissions และมีป้าย RLS enabled

## ขั้นที่ 4 ตั้งบัญชีครู (ถ้าต้องการ)
สมัครบัญชีครูผ่าน Authentication > Users > Add user แล้วรัน SQL บรรทัดท้ายไฟล์ schema.sql (แก้อีเมล) ไม่จำเป็นสำหรับการดูข้อมูลใน Dashboard ของ Supabase เพราะท่านเป็นเจ้าของโปรเจกต์อยู่แล้ว

## ขั้นที่ 5 ใส่ค่าในแอป
Project Settings > API: คัดลอก **Project URL** และ **anon / public key** (ห้ามคัดลอก service_role)
ในไฟล์ index.html หาบรรทัด `const CLOUD_CFG={url:'',key:'',` ใส่สองค่าระหว่างเครื่องหมาย ' ' แล้วบันทึกขึ้น GitHub

## ใช้งานจริง
- **ดูข้อมูล:** Table Editor > latest_submissions (ผลล่าสุดต่อคนต่อภาคเรียน) ส่งออก CSV ได้ แล้วนำคอลัมน์ report_line ไปวางในแดชบอร์ดเดิมได้ทีละบรรทัด
- **นักเรียนลืมรหัสผ่าน:** Authentication > Users ค้นหารหัสนักเรียน@students.sanor-app.com แล้ว Delete user ผลที่ส่งไปแล้วไม่หาย นักเรียนสมัครใหม่ด้วยรหัสเดิมและตั้งรหัสผ่านใหม่
- **ขอลบข้อมูล (PDPA):** ลบแถวใน students (ผลที่ส่งจะถูกลบตามอัตโนมัติ) แล้วลบ user ใน Authentication
- **จบการวิจัย:** ส่งออกข้อมูลเก็บไว้ แล้วกำหนดวันลบข้อมูลตามที่แจ้งผู้ปกครอง

## ข้อจำกัดที่ต้องบอกตรง ๆ
- ผลคะแนนยังคำนวณในมือถือนักเรียน ระบบนี้ยืนยันได้ว่า **รหัสนักเรียนตรงกับบัญชีที่ล็อกอิน** และผลที่ส่งแล้วแก้ไม่ได้ แต่ยืนยันไม่ได้ว่านักเรียนไม่ได้ดัดแปลงตัวเลขในเครื่องตัวเอง
- ยังไม่ได้ทดสอบกับ Supabase จริงและมือถือจริง (ทดสอบกับเซิร์ฟเวอร์จำลองและ Postgres ในเครื่องเท่านั้น) ให้ทดลองด้วยรหัสทดสอบก่อนเปิดจริง และตรวจว่า domain อีเมลสมมติ (`students.sanor-app.com`) ถูกรับโดย Supabase ถ้าไม่ผ่านให้เปลี่ยนค่า `domain` ใน CLOUD_CFG
